Webcam intrinsic calibration

Checkerboard capture · Python OpenCV · intrinsic matrix + FOV

HOW TO
  1. If you have a printed board, enter the board’s inner corner counts and square size in mm (or pick an iPhone preset if you use a phone screen board which assumes you are using Lens Pattern app).
  2. Start the camera, then begin capture and follow the on-screen pose prompts.
  3. Hold the board steady in the guide — the app auto-captures when detection and alignment look good.
  4. When you have enough views, compute intrinsics and download the JSON.

For a pre-made checkerboard on an iPhone, download the Lens Pattern app. In that app, set the checkerboard size to 5.
